# Мини-склад

Сайт учёта склада для BMS Smart Home: товары, приход, выдача на объекты, отмена операций, история.
Работает в браузере на компьютере и на телефоне. Запускается на своём компьютере (localhost).

## Запуск на Windows двойным щелчком

1. Установите Node.js с https://nodejs.org (кнопка LTS).
2. Откройте папку `mini-sklad` и дважды щёлкните **`start-sklad.cmd`**.
3. При первом запуске откроется Блокнот с файлом `.env` — впишите пароли после `=`, сохраните (Ctrl+S), закройте.
4. Браузер сам откроет http://localhost:8000. Чтобы остановить сайт — закройте чёрное окно.

## Запуск из терминала (любая система)

1. Установите **Node.js 22.9 или новее**: https://nodejs.org (кнопка LTS). Других программ и библиотек не нужно.
2. Скачайте код (`git clone https://github.com/leo-ramsey/mini-sklad` или архив) и откройте папку `mini-sklad` в терминале.
3. Задайте пароли: скопируйте `.env.example` в `.env` и впишите пароли трёх пользователей.
   ```bash
   copy .env.example .env
   ```
   (на macOS/Linux — `cp .env.example .env`)
4. Запустите:
   ```bash
   npm start
   ```
5. Откройте в браузере **http://localhost:8000**

Остановить — `Ctrl+C`. Данные хранятся в `data/sklad.json` и остаются после перезапуска.
Чтобы начать с пустого склада, остановите сервер и удалите папку `data`.

**С телефона:** в `.env` поставьте `HOST=0.0.0.0`, перезапустите и откройте на телефоне в той же Wi-Fi сети
`http://<IP-компьютера>:8000` (IP — команда `ipconfig`, строка «IPv4»). По умолчанию сайт доступен только с этого компьютера.

## Пользователи

| Роль         | Логин      | Что может |
|--------------|------------|-----------|
| Руководитель | `director` | Всё: товары, приход, выдача, отмена, история; видит цены |
| Кладовщик    | `stockman` | Приход и выдача; цен не видит нигде |
| Менеджер     | `manager`  | Только смотрит остатки и историю; видит цены |

Пароли задаются в файле `.env` (его нет на GitHub) — переменные `SKLAD_PASSWORD_DIRECTOR`, `SKLAD_PASSWORD_STOCKMAN`,
`SKLAD_PASSWORD_MANAGER`. При `SKLAD_REQUIRE_ENV_PASSWORDS=1` без них вход закрыт.
Если файла `.env` нет, работают тестовые пароли `director123`, `sklad123`, `manager123` — только для проверки.

## Как устроено

- `server.mjs` — локальный сервер на Node.js без сторонних библиотек: отдаёт сайт и API `/api/*`.
- `src/sklad.mjs` — вся бизнес-логика. **Права проверяются на сервере**: кладовщику цены не отправляются вообще.
- `public/` — интерфейс (HTML/CSS/JS без фреймворков), языки RU / UZ.
- `data/sklad.json` — данные склада (создаётся при первом запуске).
- `tests/` — автотесты.

## Безопасность

- **Права только на сервере.** Запрещённое действие получает отказ 403, цены кладовщику не отправляются.
- **Перебор паролей.** 5 ошибок — логин блокируется на 15 минут; с одного IP — не больше 20 попыток за 15 минут.
- **Пароли** — вне кода (файл `.env`), сравниваются за постоянное время; хеш считается и для несуществующих логинов.
- **Сессии.** Случайный токен 256 бит, в базе — только его хеш. Cookie HttpOnly + SameSite=Strict, срок 12 часов.
- **CSRF.** Изменения — только JSON-запросом с этого же сайта (проверка Origin).
- **XSS.** Весь текст экранируется; Content-Security-Policy разрешает скрипты только с этого сайта.
- **DNS rebinding.** Сервер отвечает только на обращения по `localhost` или IP-адресу.
- **Файлы.** Отдаются только из `public/` — `.env`, данные и код сервера получить нельзя.
- **Сеть.** По умолчанию сервер слушает только `127.0.0.1` — с других устройств недоступен.
- **Запросы.** Больше 64 КБ — отказ; таймауты для медленных соединений; внутренние ошибки наружу не показываются.
- **Данные.** Запись атомарная (временный файл + переименование), файл доступен только владельцу.
- **Зависимости.** Нет ни одной сторонней библиотеки.
