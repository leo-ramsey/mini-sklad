# Мини-склад

Сайт учёта склада для BMS Smart Home: товары, приход, выдача на объекты, отмена операций, история.
Работает в браузере на компьютере и на телефоне. Размещается на **Netlify**.

## Как устроено

- `public/` — сам сайт (HTML/CSS/JS без фреймворков), языки RU / UZ.
- `netlify/functions/api.mjs` — серверная функция Netlify: обслуживает все адреса `/api/*`.
- `src/sklad.mjs` — вся бизнес-логика. **Права проверяются на сервере**: кладовщику цены не отправляются вообще.
- Данные хранятся в **Netlify Blobs** — встроенном хранилище Netlify, отдельная база не нужна.
  Каждая запись условная (по версии документа), поэтому одновременные операции не уводят остаток в минус.
- `tests/` — автотесты.

## Публикация на Netlify

**Способ 1 — из GitHub (рекомендуется).** Netlify → *Add new site* → *Import an existing project* → GitHub →
репозиторий `mini-sklad` → *Deploy*. Настройки сборки подтянутся из `netlify.toml` сами.
После каждого `git push` сайт обновляется автоматически.

**Способ 2 — из командной строки** (нужен Node.js 18+):
```bash
npm install
npx netlify-cli login
npx netlify-cli deploy --prod
```

Netlify Blobs включается автоматически, ничего настраивать не нужно.

## Запуск на своём компьютере

Нужен Node.js 18+ (https://nodejs.org).
```bash
npm install
npx netlify-cli dev
```
Откройте адрес, который покажет команда (обычно http://localhost:8888).

## Пользователи

| Роль         | Логин      | Пароль        | Что может |
|--------------|------------|---------------|-----------|
| Руководитель | `director` | `director123` | Всё: товары, приход, выдача, отмена, история; видит цены |
| Кладовщик    | `sklad`    | `sklad123`    | Приход и выдача; цен не видит нигде |
| Менеджер     | `manager`  | `manager123`  | Только смотрит остатки и историю; видит цены |

## Автотесты

```bash
npm test
```

Тесты проверяют: пример из раздела 10 ТЗ целиком, правило «не в минус» (в том числе при одновременных запросах),
права ролей при запросах в обход экрана, отмену, двойное нажатие, деньги без ошибок округления, сообщения на узбекском.
