# Мини-склад

Веб-программа учёта склада для BMS Smart Home: товары, приход, выдача на объекты, отмена операций, история.
Открывается в браузере на компьютере и на телефоне.

## Запуск за 5 минут

Нужен только **Python 3.9+**. Сторонние библиотеки не нужны: используются только стандартная библиотека Python и встроенная база SQLite.

1. Установите Python с https://www.python.org/downloads/ (на Windows отметьте «Add Python to PATH»).
2. Скачайте код:
   ```bash
   git clone <ссылка на репозиторий>
   cd mini-sklad
   ```
   или распакуйте архив и откройте папку `mini-sklad` в терминале.
3. Запустите:
   ```bash
   python server.py
   ```
   На macOS/Linux вместо `python` может понадобиться `python3`.
4. Откройте в браузере **http://localhost:8000**

Чтобы открыть программу с телефона в той же Wi-Fi сети, используйте адрес `http://<IP-компьютера>:8000`.
Другой порт задаётся так: `python server.py 8080`.

Данные хранятся в файле `sklad.db` рядом с `server.py` и остаются после перезапуска.
Чтобы начать с чистого склада, остановите программу и удалите `sklad.db`.

## Пользователи

| Роль         | Логин      | Пароль       | Что может |
|--------------|------------|--------------|-----------|
| Руководитель | `director` | `director123` | Всё: товары, приход, выдача, отмена, история; видит цены |
| Кладовщик    | `sklad`    | `sklad123`    | Приход и выдача; цен не видит нигде |
| Менеджер     | `manager`  | `manager123`  | Только смотрит остатки и историю; видит цены |

## Автотесты

```bash
python -m unittest discover tests
```

26 тестов: пример из раздела 10 ТЗ целиком, правило «не в минус» (в том числе при одновременных запросах),
права ролей при запросах в обход экрана, отмена, двойное нажатие, деньги без ошибок округления,
сохранение данных после перезапуска, сообщения на узбекском.

## Устройство

- `server.py` — HTTP-сервер и вся бизнес-логика. Права проверяются на сервере: кладовщику цены не отправляются вообще.
- `static/` — интерфейс (HTML/CSS/JS без фреймворков), языки RU / UZ.
- `tests/` — автотесты.
- `ПИСЬМО.md` — что сделано, какие решения приняты и почему.
